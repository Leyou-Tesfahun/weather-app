
# Weather Dashboard 🌦️

A responsive weather dashboard that displays current weather conditions for cities worldwide, built with React and Tailwind CSS.

## Features ✨

- **Real-time Weather Data**: Fetches from OpenWeatherMap API
- **City Search**: Find weather by city name
- **Current Conditions Display**:
  - Temperature (°C/°F toggle)
  - Weather description and icon
  - Humidity percentage
  - Wind speed and direction
- **Responsive Design**: Works on all device sizes
- **Clean UI**: Modern, user-friendly interface

## Technologies Used 🛠️

- **Frontend**: React.js
- **Styling**: Tailwind CSS
- **API**: OpenWeatherMap
- **Build Tool**: Vite
- **Deployment**: Netlify
